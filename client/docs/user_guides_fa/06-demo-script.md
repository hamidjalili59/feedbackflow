# سناریوی کامل دمو برای ارائه اپلیکیشن

این سناریو برای یک ارائه ۲۰ تا ۳۰ دقیقه‌ای مناسب است.

## بخش اول: آماده‌سازی مدیر

1. با مدیر وارد شوید.
2. داشبورد را نشان دهید.
3. توضیح دهید که داده‌ها بعد از انتشار فرم و ثبت پاسخ پر می‌شوند.
4. یک معلم، یک دانش‌آموز و یک والد بسازید.
5. والد و دانش‌آموز را به هم وصل کنید.

## بخش دوم: کلاس و بخش مخاطبان

1. یک کلاس بسازید.
2. دانش‌آموز را عضو کلاس کنید.
3. یک بخش مخاطبان بسازید.
4. شماره موبایل دانش‌آموز یا والد را در بخش مخاطبان وارد کنید.
5. توضیح دهید که مدیر لازم نیست UUID بداند.

## بخش سوم: ساخت فرم با معلم

1. با معلم وارد شوید.
2. فرم رضایت کلاس بسازید.
3. فیلد NPS یا امتیاز عددی اضافه کنید.
4. فرم را برای تایید ارسال کنید.

## بخش چهارم: تایید و انتشار

1. با مدیر وارد شوید.
2. فرم را در صف تایید نشان دهید.
3. فرم را تایید کنید.
4. هدف‌گیری فرم را روی کلاس یا بخش مخاطبان تنظیم کنید.
5. فرم را منتشر کنید.

## بخش پنجم: پاسخ‌دهی

1. با دانش‌آموز وارد شوید.
2. فرم جدید را در داشبورد باز کنید.
3. پاسخ ثبت کنید.
4. اگر فرم برای والد هم قابل مشاهده است، با والد وارد شوید و وضعیت فرزند را نشان دهید.

## بخش ششم: تحلیل و پیگیری

1. با مدیر داشبورد را باز کنید.
2. کارت مشارکت، رضایت و کیفیت پاسخ‌ها را توضیح دهید.
3. یک شاخص داینامیک جدید بسازید.
4. اتصال داده‌ها را به درصد امتیاز پاسخ‌ها یا یک فیلد مشخص وصل کنید.
5. یک قاعده فعالیت بسازید: اگر امتیاز کمتر از ۵۰ شد، فعالیت پیگیری برای یک کاربر مسئول بساز.
6. یک پاسخ کم‌امتیاز ثبت کنید و آخرین فعالیت‌ها را نشان دهید.
