# راهنمای دانش‌آموز و والد

این نقش‌ها برای پاسخ‌دهی و مشاهده داده‌های مرتبط طراحی شده‌اند.

## دانش‌آموز

1. وارد حساب دانش‌آموز شوید.
2. داشبورد، فرم‌های جدید و آخرین نظرسنجی‌ها را ببینید.
3. فرم قابل پاسخ را باز کنید.
4. پاسخ‌ها را ثبت کنید.
5. اگر اجازه مشاهده نتیجه وجود داشته باشد، نتیجه یا پاسخ ثبت‌شده را ببینید.

## والد

1. وارد حساب والد شوید.
2. داشبورد والد، فرزندان متصل‌شده را نشان می‌دهد.
3. فرزند را انتخاب کنید تا پیشرفت و فرم‌های مرتبط با او دیده شود.
4. فرم‌های قابل پاسخ یا قابل مشاهده را باز کنید.
5. اگر فرم برای والد یا فرزند اختصاص داده شده باشد، در لیست نظرسنجی‌ها دیده می‌شود.

## چرا ممکن است فرم دیده نشود؟

- فرم هنوز منتشر نشده است.
- فرم برای نقش، کاربر، کلاس، گروه یا بخش مخاطبان این کاربر هدف‌گیری نشده است.
- زمان شروع فرم هنوز نرسیده است.
- مهلت پاسخ‌دهی تمام شده است.
- کاربر قبلا پاسخ داده و فرم فقط یک پاسخ برای هر کاربر مجاز می‌داند.

## دمو پیشنهادی

1. با مدیر یک دانش‌آموز و والد بسازید.
2. رابطه والد و دانش‌آموز را برقرار کنید.
3. یک فرم را برای نقش دانش‌آموز یا کلاس دانش‌آموز هدف‌گیری کنید.
4. با دانش‌آموز پاسخ دهید.
5. با والد داشبورد فرزند را بررسی کنید.
