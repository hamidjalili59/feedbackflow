# راهنمای فرم‌ها، انتشار و لینک عمومی

فرم‌ها هسته اصلی اپلیکیشن هستند.

## ساخت فرم

1. وارد بخش فرم‌ها شوید.
2. فرم جدید بسازید.
3. عنوان، توضیح، دسته‌بندی و تنظیمات پاسخ‌دهی را وارد کنید.
4. فیلدهای فرم را در سازنده فرم اضافه کنید.

## انواع فیلدها

نمونه فیلدهای قابل استفاده:

- متن کوتاه و بلند
- ایمیل و تلفن
- عدد، اعشار، تاریخ و زمان
- تک‌گزینه‌ای، چندگزینه‌ای و کشویی
- امتیاز ستاره‌ای، عددی، اسلایدر، لیکرت و NPS
- بله/خیر و سوییچ
- آپلود فایل و تصویر
- امضا، موقعیت مکانی، رتبه‌بندی
- عنوان بخش، توضیح، جداکننده و صفحه‌بندی

## تنظیمات پاسخ‌دهی

- پاسخ ناشناس
- یک پاسخ برای هر کاربر
- امکان ویرایش بعد از ثبت
- زمان شروع و پایان
- محدودیت تعداد پاسخ
- حالت پاسخ‌دهی مهمان یا لینک عمومی

## هدف‌گیری فرم

از پنل مدیریت فرم‌ها می‌توانید مشخص کنید فرم برای چه کسانی قابل دیدن یا پاسخ دادن باشد:

- نقش، مثل دانش‌آموز یا والد
- یک کاربر با شماره موبایل
- کلاس، گروه یا دپارتمان از لیست موجود
- بخش مخاطبان
- کل سازمان

## انتشار و تایید

- معلم به صورت پیش‌فرض فرم را برای تایید ارسال می‌کند.
- مدیر یا ادمین فرم را تایید می‌کند.
- بعد از تایید، فرم منتشر می‌شود.
- مدیران معمولا می‌توانند مستقیم منتشر کنند.

## لینک عمومی

اگر فرم با لینک عمومی منتشر شود:

1. لینک عمومی ساخته می‌شود.
2. تنظیمات محافظت عمومی را بررسی کنید.
3. محدودیت IP، اثرانگشت، token و cooldown می‌تواند از سوءاستفاده جلوگیری کند.
4. پاسخ‌دهنده مهمان می‌تواند بدون حساب کاربری پاسخ دهد، اگر فرم اجازه بدهد.
