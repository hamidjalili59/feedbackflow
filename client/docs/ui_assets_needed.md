# UI assets and decisions still needed

برای رسیدن به بیشترین شباهت با طرح‌ها، این موارد هنوز بهتر است از طراح یا تیم محصول گرفته شود:

1. فایل Figma اصلی برای موبایل، تبلت و دسکتاپ؛ مخصوصاً spacing، shadow و radius دقیق کارت‌ها.
2. خروجی SVG/PNG جداگانه برای avatarهای دانش‌آموز، معلم، مدیر و duck/child illustrationهای داخل اسکرین‌ها.
3. خروجی جداگانه برای آیکن‌ها و emoji scale. فعلاً UI با emoji native سیستم ساخته شده تا وابستگی asset نداشته باشد.
4. تعریف دقیق breakpoint دسکتاپ: عرض container اصلی، تعداد ستون‌ها، حداقل عرض cardها و رفتار sidebar.
5. جدول نهایی شاخص‌های پیش‌فرض سازمان: عنوان فارسی، کلید انگلیسی، نوع نمایش، بازه score، رنگ و آیکن.
6. قوانین mapping هر شاخص به فرم/field: مثلاً «ورزش» از کدام questionها و با چه weight محاسبه شود.
7. وضعیت‌های دقیق نظرسنجی و متن CTA برای هر نقش: والد، دانش‌آموز، معلم، مدیر، CEO.
8. متن empty-stateها و error-stateها با لحن نهایی برند.
9. تصویر یا icon رسمی برای ورود میهمان و حالت public survey.
10. تصمیم محصول درباره مدیریت Metric و Audience Segment در client: فقط نمایش باشد یا CRUD کامل داخل داشبورد اضافه شود.
